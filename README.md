
# Strategy Tree Planner

A lightweight local-first strategic planning web app.

## Features

- Infinite hierarchical text planning
- Strategic notation support
- AND / XOR / OR / SEQ semantics
- Decision points
- Local save
- PDF export
- Offline capable
- No subscriptions
- No backend required

## How to Run

Just open `index.html` in your browser.

## Recommended Usage

Use notation like:

    [AND]
    [XOR]
    [OR]
    [SEQ]
    [RISK]
    [ASSUMPTION]

Example:

    1 Main Goal

        [AND]
        1.1 Build Product
        1.2 Build Audience

        [XOR]
        1.3 Strategy A
        1.4 Strategy B

## Export to PDF

Click:
- Export PDF

Then:
- Save as PDF in your browser print dialog.
